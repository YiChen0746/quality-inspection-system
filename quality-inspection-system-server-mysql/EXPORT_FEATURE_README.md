# 合同审查报告导出功能

## 功能概述

本功能允许用户将AI生成的合同审查报告导出为Word文档（.docx格式），方便保存、打印和分享。

## 功能特点

1. **完整的报告内容**：包含合同的基本信息、涉及主体、合同摘要、风险条款解读、核心条款解读等
2. **专业的文档格式**：使用标准的Word文档格式，包含标题、段落、字体样式等
3. **自动命名**：文件名包含合同名称和生成日期
4. **签署区域**：文档末尾包含审查人员和审核人员的签署区域

## 技术实现

### 后端实现

1. **API端点**：`POST /api/export_review_report`
2. **依赖库**：使用`docx`库生成Word文档
3. **数据来源**：从数据库获取审查结果数据

### 前端实现

1. **导出按钮**：在合同审查结果页面提供"导出报告"按钮
2. **文件下载**：使用浏览器原生下载功能
3. **错误处理**：包含完整的错误提示和用户反馈

## 使用方法

1. 在合同审查页面上传合同文件
2. 选择分析立场（中立、甲方、乙方、第三方）
3. 等待AI分析完成
4. 在结果页面点击"导出报告"按钮
5. 选择保存位置，完成下载

## 报告内容结构

导出的Word文档包含以下章节：

1. **文档标题**：合同审查报告
2. **基本信息**：
   - 合同名称
   - 合同类型
   - 生效日期
   - 终止日期
   - 管辖权
   - 分析立场
3. **涉及主体**：合同相关方的详细信息
4. **合同摘要**：合同主要内容的概括
5. **风险条款解读**：识别出的风险条款及建议
6. **核心条款解读**：重要条款的专业分析
7. **报告信息**：生成时间和原文件名
8. **签署区域**：审查人员和审核人员签名区域

## 文件命名规则

导出的文件名格式：`{合同名称}_{生成日期}.docx`

例如：`买卖合同_2024-01-15.docx`

## 注意事项

1. 确保已完成合同审查流程
2. 需要有效的审查结果ID
3. 导出过程可能需要几秒钟时间
4. 建议在稳定的网络环境下使用

## 错误处理

- 如果未完成合同审查，会提示"请先完成合同审查"
- 如果网络连接失败，会提示"导出失败，请稍后重试"
- 如果服务器错误，会显示具体的错误信息
