# 合同统计真实数据功能

## 功能概述

本功能从数据库获取真实的合同审查和起草数据，展示用户每日的合同活动统计。

## 数据来源

### 合同审查数据
- **数据表**: `quality_results`
- **统计字段**: `created_at` (创建时间)
- **数据说明**: 每次合同审查完成后会在该表中创建一条记录

### 合同起草数据
- **数据表**: `contracts`
- **统计字段**: `created_at` (创建时间)
- **数据说明**: 每次合同起草完成后会在该表中创建一条记录

## API接口

### 获取合同统计数据
- **接口**: `GET /api/contract_statistics`
- **参数**: 
  - `days`: 查询天数，默认30天
- **返回数据**:
  ```json
  {
    "err_code": 0,
    "message": "获取成功",
    "data": {
      "summary": {
        "totalReview": 150,
        "totalDraft": 80,
        "todayReview": 5,
        "todayDraft": 3
      },
      "reviewData": [
        {"date": "2024-01-01", "count": 5},
        {"date": "2024-01-02", "count": 8}
      ],
      "draftData": [
        {"date": "2024-01-01", "count": 3},
        {"date": "2024-01-02", "count": 6}
      ],
      "dateRange": ["2024-01-01", "2024-01-02"]
    }
  }
  ```

## 前端实现

### 数据获取
- 页面加载时自动调用API获取数据
- 默认获取最近30天的统计数据
- 支持错误处理和用户提示

### 图表展示
- **审查合同统计**: 红色折线图，显示每日审查数量
- **起草合同统计**: 绿色折线图，显示每日起草数量
- **卡片统计**: 显示总数和今日数据

### 数据更新
- 页面刷新时重新获取数据
- 图表自动更新显示最新数据

## 数据库要求

### 必需字段
1. `quality_results` 表需要 `created_at` 字段
2. `contracts` 表需要 `created_at` 字段

### 数据格式
- 日期格式: `YYYY-MM-DD`
- 时间戳: 标准MySQL DATETIME格式

## 使用说明

1. **启动后端服务**:
   ```bash
   cd quality-inspection-system-server-mysql
   npm start
   ```

2. **启动前端服务**:
   ```bash
   cd quality-inspection-system-fe
   npm run dev
   ```

3. **访问统计页面**:
   - 导航到合同分析模块
   - 查看真实的数据统计图表

## 注意事项

1. **数据依赖**: 需要数据库中有真实的合同审查和起草记录
2. **时间范围**: 默认显示最近30天，可通过API参数调整
3. **性能考虑**: 大量数据时建议适当限制查询范围
4. **错误处理**: 网络异常或数据库错误时会显示友好提示

## 技术实现

### 后端技术栈
- Express.js: Web框架
- Sequelize: ORM数据库操作
- Moment.js: 时间处理

### 前端技术栈
- Vue.js: 前端框架
- Chart.js: 图表库
- Element Plus: UI组件库

## 扩展功能

### 可添加的统计维度
1. **按用户统计**: 不同用户的合同活动
2. **按合同类型统计**: 不同类型合同的分布
3. **按时间段统计**: 小时、周、月等不同时间粒度
4. **趋势分析**: 合同活动的发展趋势

### 可优化的功能
1. **数据缓存**: 减少数据库查询频率
2. **实时更新**: WebSocket推送最新数据
3. **数据导出**: 支持统计数据的导出功能
4. **自定义时间范围**: 用户可选择查询时间范围
